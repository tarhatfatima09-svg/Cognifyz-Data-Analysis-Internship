# Cognifyz Technologies – Data Analysis Internship

## 📌 About the Project

This repository contains my work completed as part of the **Data Analysis Internship at Cognifyz Technologies**. The project focuses on analyzing restaurant data using Python, Pandas, Matplotlib, and data visualization techniques to discover meaningful patterns and insights.

## 🎯 Objectives

- Analyze restaurant and cuisine data.
- Identify the most popular cuisines.
- Explore restaurant distribution across cities.
- Analyze restaurant price ranges.
- Study online food delivery availability and its relationship with ratings.
- Present findings through charts, reports, and summary statistics.

## 🛠️ Tools & Technologies

- **Language:** Python
- **Data Analysis:** Pandas
- **Visualization:** Matplotlib
- **Environment:** Visual Studio Code
- **Version Control:** Git & GitHub

## 📊 Level 1 Tasks Completed

### Task 1: Top Cuisines
- Identified the most common cuisines in the dataset.
- North Indian cuisine was the most frequently listed among the top three cuisines analyzed.

### Task 2: City Analysis
- Analyzed restaurant distribution across cities.
- New Delhi had the highest number of restaurant records in the dataset.
- Compared average restaurant ratings across cities.

### Task 3: Price Range Distribution
- Examined the distribution of restaurants across four price ranges.
- Price ranges 1 and 2 together accounted for approximately **79.12%** of the dataset.

### Task 4: Online Delivery Analysis
- Analyzed online delivery availability.
- Approximately **25.66%** of restaurants offered online delivery.
- Restaurants offering online delivery had a higher average rating in this dataset. This is an observed association, not proof of causation.
